## 🧑‍💻 Kurulum

Projeyi kendi bilgisayarında çalıştırmak için:

# Repoyu klonla
```bash
git clone https://github.com/sema27/lumina-luxe.git
```

# Klasöre gir
```bash
cd lumina-luxe
```

# Bağımlılıkları yükle
```bash
npm install
```

# Geliştirme sunucusunu başlat
```bash
npm run dev
```

# Tarayıcıda
```bash
http://localhost:3000
```
ile siteyi görebilirsin.
